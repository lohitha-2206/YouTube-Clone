🌟 About The Project

ViewTube is a fully responsive YouTube-inspired video streaming web application built to replicate the core UI and browsing experience of YouTube.

The project demonstrates modern frontend development skills, component-based architecture, responsive layouts, and dynamic content rendering.

It includes a sidebar navigation system, video cards layout, category filtering, and a clean search interface — closely resembling a real-world video streaming platform.

🚀 Features

🎥 YouTube-style video grid layout

📂 Sidebar navigation (Home, Gaming, Sports, Music, etc.)

🔍 Search bar UI

📱 Fully responsive design

🎨 Clean and modern interface
